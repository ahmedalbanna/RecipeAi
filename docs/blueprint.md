# **App Name**: FridgeChef

## Core Features:

- Ingredient Input: Simple, intuitive interface for entering ingredients.
- AI Recipe Generation: AI recipe generation based on available ingredients; if there aren't enough ingredients available, the tool provides a list of ingredients the user can easily add.
- Recipe Display: Clear display of recipes with instructions.
- Filter recipes: Options to filter recipes based on dietary restrictions.

## Style Guidelines:

- Primary color: Fresh green (#A0D6B4) to evoke feelings of freshness.
- Background color: Light green (#E8F5EF), almost white to provide contrast with the content.
- Accent color: Olive green (#73A981) for interactive elements, creating a harmonious monochromatic color scheme.
- Body and headline font: 'PT Sans' (sans-serif), suitable for both headlines and body text, providing a modern and approachable feel.
- Use simple line icons representing different food categories and ingredients.
- Clean, card-based layout for recipes, ensuring easy navigation.
- Subtle transitions on ingredient input and recipe display.
